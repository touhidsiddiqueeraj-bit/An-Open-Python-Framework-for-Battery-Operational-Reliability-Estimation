Why this matters

Grid batteries are asked: "Can you safely deliver power for the next N hours?"

  • Say yes when the battery is healthy → earn revenue
  • Say yes when it's about to fail → blackout, penalty costs
  • Say no when it would have been fine → lost revenue

Shikdar & Laaksonen (2026) built a machine learning framework to predict failure probability across multiple horizons (10–50 cycles). They reported:

  • AUC = 0.944 on 37 batteries
  • Failure rate reduction: 10.3% → 2.95%

Can we reproduce this with the public NASA dataset that most researchers use?

Our Reproducibility Pipeline

We implemented the entire framework as a modular Python package:

  • Data layer: NASALoader parses .mat files, normalizes features (SOH, voltage, current, temperature)
  • Model layer: XGBoost with per-horizon multi-output classification, isotonic calibration on validation fold
  • Dispatch layer: Threshold policies, derating, Monte Carlo market simulator
  • Evaluation: Leave-one-battery-out CV, AUC/Brier/ECE metrics, per-fold reporting

Single command: python run_all.py --quick — completes in < 10 seconds

AUC = 0.50 is exactly random. The model produces near-constant predictions across cycles because only ~2 failure events exist across training cells. Calibration preserves rank order — constant input → constant output → AUC 0.50.

A synthetic-to-real transfer test (train N=20 synthetic, test NASA) yields AUC 0.88 (95% CI: [0.860, 0.900]), indicating the synthetic generator captures real-world structure. This does NOT validate real-data training — it is a distributional similarity check.

↓ Key finding: event count, not cell count With N=12 fixed, AUC drops from 0.91 (200 events) to 0.64 (100 events) to 0.10 (2 events).

↓ Diversity caveat: Synthetic data maximizes cell diversity at every N. Real batteries share conditions — correlated degradation reduces effective diversity.

↓ Censoring intolerance: Both XGBoost and RSF fail above 20% censoring — confirmed by Uno's cumulative/dynamic AUC (per-horizon, not just macro). Degradation is genuine signal loss, not metric bias.

↓ RSF baseline added: A per-cycle RSF (single model per fold, 1−S(H) horizon risk) plateaus at AUC ~0.82 for N≥3, vs XGBoost 0.99. Multi-horizon XGBoost extracts more information from clean synthetic features.

Three Hidden Bugs We Found

Bug 1: Calibration Data Leakage

Fitting the isotonic calibrator on test data inflated AUC from an honest 0.50 to an apparent 0.74. Fix: fit on a held-out validation fold. Demonstrated on working model: +0.016 inflation persists even at high AUC.

Bug 2: Energy Unit Confusion

Revenue = energy (kWh) × price ($/MWh) — without dividing by 1000, revenue was overstated by 1000× ($3,780 vs $3.78 per battery across test period).

Bug 3: Inconsistent Baseline Metric

Baseline failure rate used label density across all horizons; model rows used conditional dispatch-based metric. Incomparable. Corrected to same conditional metric.

Takeaways

Exploratory scaling curve (synthetic, optimistic bound)

AUC vs N curve: N ≤ 5 = low (AUC < 0.95), N = 8-12 = moderate (AUC 0.97-0.98), N ≥ 12 = high (AUC > 0.98, no plateau). Key insight: ≥200 failure events drive discrimination, not cell count alone. Real-data requirements are unknown.

Open-source framework with honest reporting

Three bugs documented and fixed: calibration leakage (inflated AUC 0.50→0.74), energy unit error (1000×), inconsistent baselines. On NASA 4-cell: per-fold AUC = 0.50 (exactly random). All code is public.

Clear limitations stated

RSF baseline added (plateaus at AUC ~0.82). No Cox/Weibull comparisons. No real-data validation beyond 4 cells. Censoring intolerant above 20% (confirmed by Uno AUC). Synthetic-to-real gap (KS D=0.33). Transfer test does not validate real deployment.

Limitations & Future Work

Current limitations

  • NASA validation limited to 4 cells (all 18,650 format, lab conditions)
  • RSF baseline added: plateaus at AUC ~0.82 for N≥3 (vs XGBoost 0.99)
  • Censoring intolerant above 20% (confirmed by Uno AUC per horizon)
  • No Cox/Weibull comparisons
  • No deep learning (LSTM, TCN, Transformer) — CPU-only constraints
  • Synthetic distribution differs from real (KS D=0.33, p<0.001)
  • Transfer test: distributional similarity check, NOT real-data validation

Future work

  • Validate scaling curve on real multi-cell datasets (15+ cells)
  • Add extended baseline benchmarks (Cox PH, Weibull AFT)
  • Add cross-chemistry validation (LFP, NMC chemistries)
  • GPU-based deep learning comparisons
  • Real price data instead of AR(1) simulation
